# 后续优化与实验边界

当前版本对应 `me5418-scenes-v1` 的 151/58/131 split、`configs/stage09/C.json` 正式 C 配置、12 个 `me5418` 核心模块，以及 `models_index.json` 中三个 best 和三个 last。模型种子为 550901/551901/552901，best 是主要结果，last 是事先规定的补充结果。六模型字节、SHA、选中步数与角色以索引为准；源文件和数据来源以发布清单为准。

原正式结果保存在 `results/reference/`，新的运行写入各自输出目录。仓库整理没有改奖励、任务标准、模型计算或正式权重。新运行的验证状态与差异见[复现说明](reproduction_zh.md)。

## 已有证据与研究假设

| 事项 | 已有证据 | 仍不能确定的解释 |
| --- | --- | --- |
| 成功数 | 当前 131 题上三个 best 均高于 APF | 不能推广到任意构型或任务族 |
| 动作代价 | 550901/551901 best 的命令平滑度差于 APF；seed 间代价不同 | 不能仅从现有相关性确定哪项奖励或网络因素是原因 |
| 长训练变化 | 两个 last 的成功数低于各自 best；551901 的 last 在 test 更好 | 更久并不必然更好；退化的单一机制未定位 |
| 表示与采样 | 开发阶段 91 维表示和 20/40/40 采样有有限改善与负例 | 网络容量、采样曝光、选择偏差需进一步区分 |
| 未来参考 | 当前策略输入包括未来参考点 | 没有独立消融，不能单独归因于提前预判 |
| 安全与计算 | 存在接触带失败、一个微小自负距离、约 102 ms 计算极值 | 没有通用安全或严格实时保证，离群原因未定位 |

## 可以考虑的方向

1. 在固定成功标准下研究动作平滑与较低速度代价，同时保留完整成功数、失败和剪裁统计。
2. 分开检验观测几何、网络容量、类别采样、未来参考与探索尺度，每次明确改变因素，避免用同一组 test 反复选择。
3. 研究自碰撞处理、多个/动态障碍、不同初态和工具朝向任务；这些会改变问题范围，需要新的基线和验收条件。
4. 定位计算离群，测量包含编码、决策、控制、物理与安全的完整循环；硬件实时性与实机安全需独立验证。

这些是候选研究方向，本次未执行新的调参或研究实验。

## 开始新实验时

在当前发布仓库的新分支中开发；新配置保存为新文件，输出使用新名称。先保留当前源/配置/数据/模型 SHA 与提交版本，短检查通过后再决定正式预算。保持 240/48 Hz、主任务、安全阈值和评价分母可追溯；确需改变时另设协议和版本，不能覆盖旧结果。

`test` 已用于 Stage10 和本次复现，后续只能称为已使用的回归集合。新的泛化结论需要事先冻结的新未见评价数据；validation 也已经反复用于开发和选模。原正式结果继续保留，不删除失败、换 seed 或把表现更好的 last 改称主模型。

原实验目录保留完整历史证据，个人资料目录用于学习与解释。后续代码开发从当前发布仓库继续，按提交与清单追溯原档案。
